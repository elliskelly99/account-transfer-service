# Account Transfer Service

![CI](https://github.com/elliskelly99/account-transfer-service/actions/workflows/ci.yml/badge.svg)

#Proof-of-concept Spring Boot service for transferring funds between accounts, focused on transaction processing, data integrity, concurrency, and reliable persistence.

## Tech
- Java 21, Spring Boot, Spring Data JPA, Maven, H2
- GitHub Actions CI, CodeRabbit for Automated PR review
